\# Servlet \& Spring Core 🚀



A hands-on learning repository focused on understanding \*\*Java Servlets, Spring Core, and the fundamentals of the Spring Framework\*\*.



This repository contains practice programs, examples, experiments, and small applications created while learning backend development with Java.



\---



\## 📚 Topics Covered



\### Java Servlet



\- Servlet fundamentals

\- Servlet lifecycle

\- `HttpServlet`

\- `doGet()`

\- `doPost()`

\- Request and Response

\- `HttpServletRequest`

\- `HttpServletResponse`

\- Request parameters

\- Form handling

\- Servlet mapping

\- URL patterns

\- Servlet configuration

\- Session management

\- Cookies

\- RequestDispatcher

\- Forwarding and Redirecting

\- JSP \& Servlet integration

\- MVC fundamentals



\### Spring Core



\- Spring Framework fundamentals

\- IoC (Inversion of Control)

\- Dependency Injection

\- Constructor Injection

\- Setter Injection

\- Field Injection

\- Spring Beans

\- BeanFactory

\- ApplicationContext

\- `@Component`

\- `@Service`

\- `@Repository`

\- `@Controller`

\- `@Autowired`

\- `@Qualifier`

\- `@Primary`

\- `@Bean`

\- Bean lifecycle

\- Singleton and Prototype scopes

\- Lazy initialization

\- Configuration classes
